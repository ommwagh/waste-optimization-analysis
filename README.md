# 🌿 Waste Optimization Analysis

## 📊 Overview
This project explores product-level waste patterns in a retail environment to identify inefficiencies and areas for cost reduction. Using Excel and SQL, it highlights products with high waste, calculates waste-to-sales ratios, and analyzes performance by region.

## 🔧 Tools Used
- Microsoft Excel (PivotTables, Calculated Fields)
- SQL (for querying and summary analysis)

## 📁 Files Included
- `waste_data.xlsx` – Source dataset with product, waste, and sales info
- `waste_analysis_queries.sql` – SQL queries used for product- and region-level waste analysis

## 📌 Key Insights
- Products like **Plant & Mug** had high waste despite low sales
- Items such as **Sunflowers** maintained strong sales with minimal waste
- Certain regions showed consistently higher waste rates than others

## 🧠 Skills Demonstrated
- Waste ratio calculation and interpretation
- PivotTable summarization and formatting
- SQL: Aggregation, grouping, calculated metrics
- Data quality validation (handling division by zero, NULLs)
